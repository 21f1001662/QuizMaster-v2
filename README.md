## About
QuizMaster is an AI-powered quiz management system that allows educators to generate 
and manage quizzes while enabling students to attempt quizzes, track progress, and 
view performance analytics. The project involves building a responsive web interface with 
automated question generation, real-time assessments, and interactive learning 
features.
